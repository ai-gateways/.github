# AI Gateways

An AI gateway is the layer between applications and the models, tools, and agents they call. It handles routing, failover, authentication, budgets, guardrails, and logging in one place, so each application does not have to rebuild them.

This organization hosts open-source, vendor-neutral work on AI gateways: reference configurations, benchmarks, integration examples, and guides that apply across implementations.

## What we cover

- **LLM gateways:** one API across model providers, with routing, retries, fallbacks, caching, and cost controls.
- **MCP gateways:** central registration, authentication, and access control for [Model Context Protocol](https://modelcontextprotocol.io) tool servers.
- **Agent gateways:** discovery, access control, and observability for [agent-to-agent (A2A)](https://a2a-protocol.org) traffic.
